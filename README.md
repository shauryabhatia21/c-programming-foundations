# C Programming Foundations

Foundational C programming exercises covering core procedural concepts.

## 📌 Topics Covered

- **Basic Arithmetic & Logic**: Operators, mathematical evaluations, variables & constants
- **Conditionals**: `if-else` branching, nested conditions, `switch-case` statements
- **Loops**: `for`, `while`, and `do-while` loops with nested iterations
- **Character & ASCII**: Character classifications and ASCII value validation

## 🚀 Compilation
Compile and run with GCC:
```bash
gcc filename.c -o output
./output
```
